This script holds every diagnosis, procedure and billing code list the analysis uses. By the maintainer’s decision, the lists come from the 2025-03-25 reconstruction of the original analysis rather than from Supplementary Table 1 of the paper1. The two are identical except for diabetes and the HCPCS drug codes (below). After every code was checked against the official code sets, a few corrections were made, also below.

RcodeSource code

The full R script is available at:

  • R/code_lists.R

It is sourced by R/setup.R.

One table of codes

All lists are in one table, code_lists, with one row per code. Each row has five fields:

  • the concept (for example cryptococcosis or lumbar_puncture);
  • the code type: diagnosis, procedure or HCPCS;
  • the code system;
  • the code, without its decimal point;
  • whether the code matches exactly or as a prefix;
  • its source: the reconstruction, or the supplement for the HCPCS codes.

Every code matches exactly, except the diabetes stems. The reconstruction listed each diabetes stem alone or followed by one or two digits, which misses most ICD-10-CM diabetes codes (for example E11649). So the stems match as open prefixes, as in the supplement: E11 matches E1122 and E11649 alike. ICD-9-CM 456.20 (esophageal varices with bleeding, in diseases classified elsewhere) is added to cirrhosis; both sources list only its counterpart 456.21. The cyclosporine and tacrolimus HCPCS codes appear only in the supplement. Immunosuppression is measured from the UNOS records instead (#2), so they are not used, but they are kept, marked, in case billing data are revisited as the source. The reconstruction also has an IRIS list and a principal-diagnosis cryptococcosis list, which the paper’s analyses do not use and which are left out.

The paper reports ventriculoperitoneal shunt placement, but neither the supplement nor the reconstruction lists its codes, which the maintainer judged a copy/paste loss. The list is rebuilt from the official code sets: ICD-9-CM 02.34 and the nine ICD-10-PCS “Bypass Cerebral Ventricle to Peritoneal Cavity” codes. All ten are also in the neurosurgical list. That includes the three-character B45 in the cryptococcosis list, which therefore matches only a code recorded as B45 itself.

# Diabetes stems as open prefixes, as Supplementary Table 1 lists them (250*,
# E08*, E09*, E10*, E11*, E13*), so every subcode matches, including 6- and
# 7-character ICD-10-CM codes such as E11649. The reconstruction's version
# stopped at two extra digits and missed most ICD-10 diabetes codes.
diabetes_prefix_codes <- tibble(
  concept = "diabetes",
  code_type = "diagnosis",
  code_system = c("ICD-9-CM", rep("ICD-10-CM", 5)),
  code = c("250", "E08", "E09", "E10", "E11", "E13"),
  match = "prefix",
  source = "supplement"
)

This script holds every diagnosis, procedure and billing code list the analysis uses. By the maintainer's decision, the lists come from the 2025-03-25 reconstruction of the original analysis rather than from Supplementary Table 1 of the paper [@fiorica2025]. The two are identical except for diabetes and the HCPCS drug codes (below). After every code was checked against the official code sets, a few corrections were made, also below.

## One table of codes

All lists are in one table, `code_lists`, with one row per code. Each row has five fields:

- the **concept** (for example `cryptococcosis` or `lumbar_puncture`);
- the **code type**: diagnosis, procedure or HCPCS;
- the **code system**;
- the **code**, without its decimal point;
- whether the code matches **exactly** or as a **prefix**;
- its **source**: the reconstruction, or the supplement for the HCPCS codes.

Every code matches exactly, except the diabetes stems. The reconstruction listed each diabetes stem alone or followed by one or two digits, which misses most ICD-10-CM diabetes codes (for example `E11649`). So the stems match as open prefixes, as in the supplement: `E11` matches `E1122` and `E11649` alike. ICD-9-CM 456.20 (esophageal varices with bleeding, in diseases classified elsewhere) is added to cirrhosis; both sources list only its counterpart 456.21. The cyclosporine and tacrolimus HCPCS codes appear only in the supplement. Immunosuppression is measured from the UNOS records instead ([#2](https://github.com/VagishHemmige/Fiorica-cryptoccoccus-analysis/issues/2)), so they are not used, but they are kept, marked, in case billing data are revisited as the source. The reconstruction also has an IRIS list and a principal-diagnosis cryptococcosis list, which the paper's analyses do not use and which are left out.

The paper reports ventriculoperitoneal shunt placement, but neither the supplement nor the reconstruction lists its codes, which the maintainer judged a copy/paste loss. The list is rebuilt from the official code sets: ICD-9-CM 02.34 and the nine ICD-10-PCS "Bypass Cerebral Ventricle to Peritoneal Cavity" codes. All ten are also in the neurosurgical list. That includes the three-character `B45` in the cryptococcosis list, which therefore matches only a code recorded as `B45` itself.

## Immunosuppressive drug classes

UNOS records each immunosuppressive drug by a numeric code (`RX_CD`), with free text when the drug is "other". This table assigns each code to one of the classes the paper reports. The mapping is the reconstruction's, checked against the official labels in Appendix C. Three codes it missed are added: 57 (generic Myfortic), 58 (generic sirolimus) and 59 (Envarsus XR). Rituximab, IVIG and muromonab, which the reconstruction also flagged, are left out because the paper doesn't report them.

The free-text table keeps the reconstruction's spellings, including the misspellings found in the data.

## Regions

USRDS records state of residence as a FIPS code. This table assigns each code to a Census region and division.

- **The 48 contiguous states and DC** follow the Census Bureau.
- **Alaska and Hawaii** are grouped with the territories as "Outside", as in the reconstruction, rather than in the West as the Census Bureau does. No one is excluded by geography ([#12](https://github.com/VagishHemmige/Fiorica-cryptoccoccus-analysis/issues/12)).
- **Every other valid non-state code** (territories, foreign) is "Outside". The reconstruction left some of these, such as Guam and the Virgin Islands, as missing.
